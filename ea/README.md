# Step100Man — 「1万円から100万円を目指す戦略とロット目安」MT5 EA

元画像（@FxTraderCourse のインフォグラフィック）の5ブロックを、そのまま
MT5 の Expert Advisor にしたもの。入力グループが画像のブロックに1対1で対応する。

| 画像のブロック | 実装先 |
| --- | --- |
| ① 全体の戦略 | `Step100Man.mq5` の入力 ＋ `Manager.mqh` |
| ② 資金ごとのロット目安 | `Step100Man/LotTable.mqh`（数値は画像のまま） |
| ③ エントリーポイントの例（6つ） | `Step100Man/Signals.mqh` |
| ④ 利確・損切りのルール | `Step100Man/Manager.mqh` |
| ⑤ 注意点 | `Step100Man/Filters.mqh` ＋ ロット据え置きの保証 |

---

## インストール

1. MT5 で **ファイル → データフォルダを開く**
2. `MQL5/Experts/` に、このフォルダの中身をそのまま置く

```
MQL5/Experts/
  Step100Man.mq5
  Step100Man/
    Common.mqh
    LotTable.mqh
    Structure.mqh
    Signals.mqh
    Filters.mqh
    Manager.mqh
```

3. MetaEditor で `Step100Man.mq5` を開いて **コンパイル**（F7）
4. チャートにドラッグ。**「自動売買を許可する」はシグナル確認が済むまで入れない**

`#include` は相対パス指定なので、`Step100Man/` フォルダは `.mq5` と同じ場所に
置くこと。`MQL5/Include/` に移す必要はない。

---

## 動作モード

初期値は **`EA_SIGNAL_ONLY`（シグナル通知のみ）**。発注せず、判定が出たときに
ログ・ポップアップ・チャートの矢印だけを出す。

画像の入口は「複数回反発した線」「キリ番の反発」「ダマシを確認してから」など、
どれも人が見て判断する前提の書き方になっている。まず通知モードで何日か回し、
自分の目で見て納得できる場所に矢印が出るか確かめてから `EA_AUTO` にする。

## ② ロット表について（重要）

`LotTable.mqh` は画像の表を**数値そのまま**持っている。

```
 5千円 0.02 /  1万円 0.03 /  2万円 0.06 /  3万円 0.09 /  5万円 0.15
 7万円 0.20 / 10万円 0.30 / 15万円 0.45 / 20万円 0.60 / 30万円 0.90
50万円 1.50 / 60万円 1.80 / 75万円 2.10 / 90万円 2.70 /100万円 3.00
```

### 表に含まれる2つの歪み（直していない）

**1. 比率から外れる段がある。** 1万円以降はおおむね「1万円あたり 0.003 ロット」で
並ぶが、**7万円（0.20、比率なら 0.21）** と **75万円（2.10、比率なら 2.25）** だけ
低い。忠実再現のため直していない。揃えたい場合は `LotTierVol[]` を書き換える。

**2. 金額列は 1ドル＝125円 前提。** 画像の「1回の利益目安」の低い方の列は、
15段すべてが `ロット × 50,000円` ちょうどで一致する。つまり
**1ロット・1pip ＝ 1,250円**（＝$10/pip を 125円/ドルで換算）が前提。

これは `test_ea_lots.py` で検算済み。**いまのドル円（約159円）では、利益も損失も
画像の数字より約 27% 大きくなる。** EA は起動時に、実際の口座・銘柄での
1pip あたりの金額と想定損益をログに出すので、そちらを正とすること。

### 1回あたりのリスク

画像は**損切りも利確と同じ 40〜50pips** なので、「1回の利益目安」の列は
そのまま「1回の損失目安」でもある。

| 資金 | ロット | 40pips | 50pips | 資金に対する割合 |
| --- | --- | --- | --- | --- |
| 1万円 | 0.03 | 1,500円 | 2,000円 | **15〜20%** |
| 10万円 | 0.30 | 15,000円 | 20,000円 | **15〜20%** |
| 100万円 | 3.00 | 150,000円 | 200,000円 | **15〜20%** |

どの段でも 15〜20%。3連敗でおよそ半分になる。これが表の設計そのもの。

`RiskCapPercent` に値（例 `2.0`）を入れると、表のロットに「資金の◯%以上は
損切りで失わない」という上限を掛けられる。**初期値は 0（＝無効、表のまま）。**
画像には無い追加機能なので、忠実に動かしたいならそのままでよい。

### ロットを上げる／上げない

- 表の段は**残高（または有効証拠金）だけ**で決まる。
- 直前が勝ちか負けかは一切見ない。⑤注意点の
  「1回の負けで大きくロットを上げない」「資金が増えても同じルールを守る」は、
  ナンピン・マーチンの類を実装しないことで保証している。
- ボーナスを含めたい業者では `TableBasis = BASIS_EQUITY` にする。
- 円以外の口座は `<通貨>JPY` の気配から自動換算する。取れないときだけ
  `ManualUsdJpy` を使う。

## ③ 6つのエントリーパターン

元画像は手書きのチャート図なので、コードは「その図を素直に数式にしたらこうなる」
という**解釈**。判定はすべて確定足のみ（形成中の足は見ない）。閾値は全部入力で動く。

| # | 画像 | 実装した判定 |
| --- | --- | --- |
| 1 | ブレイクの逆指値狙い | `MinTouches` 回以上反発した水平線を、確定足の終値が `BreakBufferPips` 超えて抜けた直後 |
| 2 | キリ番での反発狙い | キリ番（クロス円 0.50 刻み／他 50pips 刻み）に安値が触れ、終値は上、形は下ヒゲ否定か包み足 |
| 3 | レジサポ転換の押し目買い | 直近 `RoleReversalBars` 本で抵抗線を上抜け済み → その線まで押して、陽線終値で線の上に留まる |
| 4 | チャートパターン形成後のブレイク | ダブルボトム／トップのネックライン抜け、または三角持ち合い（高値切り下げ＋安値切り上げ）の辺を抜け |
| 5 | ダマシ回避の確認後エントリー | 一度抜けて終値で戻された足が `FakeOutBars` 内にあり、いま再度抜けている ＋ 安値切り上げ |
| 6 | 逆行後の反発狙い | 直近安値圏で、下ヒゲ ≥ `WickRatio` × 実体、終値が足の上位 40% に入る |

1→6 の順に見て、最初に当たったものを採用する（画像の並び順＝優先順位として扱う）。
売りはすべて上下反転で同じ定義。

「無理なエントリーをしない（チャンスがある時だけ）」は、
`MaxTradesPerDay`（1日の回数上限）と各パターンの確認条件で表現している。

## ①④ 建玉の扱い

1. エントリー時に **SL と TP を必ず付ける**。付かなければその建玉を即閉じる。
2. `PartialAtPips`（既定 25pips）で **`PartialPercent`%（既定 50%）を決済**。
   残りは伸ばす。※業者の最小ロットで割れない場合は分割を飛ばす。
3. `BreakEvenAtPips`（既定 30pips、画像どおり）で **SL を建値へ**。
4. `TrailStartPips` 以降は `TrailStepPips` 幅でトレーリング。
5. `InvalidationPips` ぶん根拠の線を逆に割ったら、含み損のうちに撤退
   （「EN値の根拠が崩れたらすぐに撤退」）。

分割済み／建値済み／根拠の線は、ターミナルのグローバル変数
（`S100M_*`）に建玉チケットごとに持たせている。EA を入れ直しても続きから動く。
閉じた建玉ぶんは毎ティック掃除する。

### 追加エントリー

`UsePyramiding`（既定 ON）。**ブレイク系（パターン 1・3・4・5）でのみ**追加する。
`AddOnlyAfterBreakEven`（既定 ON）なら、既存建玉が建値に移ってからしか増やさない。
上限は `MaxAddPositions`（既定 2本）。逆向きのポジションがあるときは入らない（ドテンしない）。

## ⑤ 門番（注意点の実装）

| 入力 | 既定 | 働き |
| --- | --- | --- |
| `MaxSpreadPips` | 2.5 | これより広ければ入らない |
| `UseNewsFilter` | true | MT5 内蔵カレンダーで、取引通貨に関係する重要度「高」の指標の前後 30 分は入らない |
| `BlockIfNoCalendar` | false | カレンダーを引けない環境でも止めるか |
| `AvoidHoursCsv` | 空 | `"21:30-23:00,08:00-08:30"` のように時間帯を塞ぐ（サーバー時刻、日またぎ可） |
| `MaxPositionsTotal` | 3 | 同時保有の上限 |
| `MaxTradesPerDay` | 3 | 1日の新規回数の上限（感情エントリー防止） |
| `MaxDailyLossPercent` | 10 | 1日の損失がこれに達したら今日は新規停止 |
| `CloseAllOnDailyLoss` | true | そのとき建玉も全部閉じるか |

ストラテジーテスターではカレンダーが引けないことがある。その場合
`UseNewsFilter` の結果は「指標なし」として通る（`BlockIfNoCalendar=false` のとき）。
